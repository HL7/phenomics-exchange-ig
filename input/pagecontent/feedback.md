# Providing feedback

You can provide feedback through the HL7 JIRA system if you already have an account or fill in the Google form linked below. 

For JIRA, please follow [this link](https://jira.hl7.org/projects/FHIR/issues) and click the blue `Create` button on the top of the page. You can change the `Issue Type`. In the `Spacification` field please start typing `pheno` and then select the `Phenomics Exchange...` entry.  The only other required field is the `Summary` field, which becomes the title. Please add any additional information to the `Description` textbox.

Alternatively, please use [this Google Form](https://docs.google.com/forms/d/e/1FAIpQLSfVT0sybY9sT6x1jCJTK5Sn2OuIu3L8dxrnTkMLbrAVPJojuQ/viewform?usp=publish-editor) to share any IG feedback.

You can complete [this form](https://docs.google.com/forms/d/e/1FAIpQLScOoCjm9rIAEyWqCZT2DkE6mSGKfXIPcK9RbQtoSNy0-5KjyA/viewform?usp=header) if you are interested in connecting with the project's team.
